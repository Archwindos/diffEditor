# DiffEditor

本地文本差异查看与编辑器。支持两侧编辑、按块双向替换、草稿恢复，以及确认后备份并保存。适用于 `.tex`、`.md`、`.bib` 和其他纯文本；不处理图片、PDF 或 Word。

## 打开与使用

解压便携包，双击 `DiffEditor.exe`。无需安装、登录或联网。请完整保留程序旁的资源文件。

1. 点击 **新建文本比较**，直接在左右两侧输入或粘贴文本，无需选择文件。点击 **打开文件**：左右两侧从同一文件开始；可以一次选择多份文件，每份分别审阅。点击 **双文件比较** 则选择两个独立文件。也可拖入文件。
2. 在任意一侧直接编辑，或用差异块中间的箭头将该块替换到另一侧。长段落默认自动换行；滚动条宽 6 像素，滚动时显示，停止后自动隐藏。自动换行、折叠相同行、差异跳转、查找、撤销和重做都在工具栏。
3. 编辑会缓存为草稿，**不会自动写入原文件**。确认前可以切换文件或正常关闭；异常退出可恢复最近已经缓存的版本。
4. 点击需要保存的一侧的 **保存此侧**，核对完整路径、编码、备份位置和内容，再点击 **确认并保存**。`Ctrl+S` 只打开确认窗口。
5. 最终保存成功后，只以全宽单栏显示你保留的那一侧，可查找、复制和自动换行；重新打开仍显示该版本。同一原稿的两侧旧草稿均不能继续覆盖该原稿。点击 **继续编辑**，从刚保存的磁盘版本开启新一轮。两个独立文件的状态分别记录，另一侧尚未完成时可点击 **继续审阅另一文件** 返回比较。
6. 无文件文本的 **另存为…** 会先让你选择新文件位置，再显示最终保存确认。两侧各自选择位置；选择已有文件时会拒绝覆盖，请改选新文件名。输入和比较本身不需要保存为文件。
7. 在比较列表中点击 **关闭**，将其收入 **已关闭**，随时可以重新打开，双侧草稿都会保留。点击 **删除** 并确认，会移除该比较及缓存文本；正式文件、已保存内容和备份均不会被删除。删除不可恢复。

左下角 **设置** 中的 **关闭窗口后转到后台** 默认开启。点击窗口叉号后，先缓存草稿，再隐藏到右下角系统托盘（可能位于隐藏图标区）。点击托盘图标或桌面快捷方式可重新打开；右键托盘图标选择 **退出** 才会彻底退出。取消勾选后，叉号会在缓存草稿后退出程序。设置会保留，不新增快捷键。

编码默认识别 UTF-8/BOM、带 BOM 的 UTF-16；旧中文文本可选择 GB18030 后打开。保存编码可由用户明确选择。文件中原有的混合换行及末尾换行会尽量按原始行映射保留；未修改的文件逐字节保留。

## 草稿与备份

- 草稿默认位于 `%LOCALAPPDATA%\DiffEditor\drafts`；Codex 候选输入位于同级 `inbox`。这些是软件草稿，不是正式稿。
- 每次确认保存，旧稿备份到原文件同目录的 `.diffeditor-backups`。备份名称唯一，不覆盖、不自动清理；保存后可点击 **查看备份**。
- 保存前检查原稿内容及文件身份。原稿在外部被修改、替换或删除时，停止写入并保留草稿。点击 **基于磁盘继续** 会保留旧审阅记录，并从当前磁盘建立新一轮；需要的旧草稿内容可以再复制过去。
- 若备份或写入失败，界面显示原因。中断后仅当目标与备份都验证通过才恢复“已保存”；不自动重写或回滚文件。
- 应用关闭不删除草稿或备份。删除比较会清除相应缓存文本；为避免重复提交复活已删除比较，软件仍保留提交标识、删除状态和保存回执等最小记录。

原稿哈希检查与文件替换之间仍存在很短的竞争窗口，不建议在确认保存的同时让其他程序写同一文件。此软件与 skill 实现审批工作流，不改变 Codex 的操作系统权限，不能拦截绕过软件的直接写盘。

## 配合 Codex

安装随附的 `skill/diffeditor` 完整文件夹到个人 Codex skills 目录。当前项目中相同源码位于 `skills/diffeditor`，skill 名称为 **diffeditor**。可显式说：

> 使用 $diffeditor 修改这篇论文。先把修改送到 DiffEditor，我自己审阅并确认保存。

AI 通过以下命令连接本地命名管道：`baseline` 读取不可变基线，`submit` 用 JSON 提交候选稿，`status` 查询逐文件结果；结果均为结构化 JSON。配套 Python 助手可直接用参数数组调用，无需让 AI 操作窗口或拼接正文到命令行。命令如下：

```text
diffeditor.cmd baseline "D:\论文\main.tex"
diffeditor.cmd submit --file "候选 JSON 的绝对路径"
diffeditor.cmd status "reviewId"
```

`submit` 的 JSON 结构、UTF-8 输入和错误处理见项目 [CLI 文档](docs/cli.md) 或随附 skill 的 `references/cli.md`。便携包的命令行借用自带 Electron 运行，不要求安装 Node。命令行没有批准或保存命令；聊天中的“同意”也不会替代软件中的确认。

skill 的确定性 Python 助手可以通过 `DIFFEDITOR_HOME` 指定包含 `diffeditor.cmd` 的目录；本机项目路径也可自动发现。不要把真实论文当作测试样本。

## 从源码构建

需要 Node.js 22.12+ 或 24，以及 npm。Windows 的 AI 助手集成测试还需要 PATH 中的 Python 3；也可用 `DIFFEDITOR_TEST_PYTHON` 指定 Python 可执行文件。

```text
npm ci
npm run typecheck
npm test
npm run build
npm start
npm run package
```

当前便携目录位于 `release/0.1.3/win-unpacked`，完整复制或打包这个目录。升级时先从托盘菜单退出旧版（旧版没有托盘时正常关闭），再启动新版；原有缓存草稿会继续保留。首次安装和打包需要下载公开依赖，运行软件时不需要网络。软件仅在本机命名管道上处理 baseline / submit / status，桌面渲染器阻止远程网络请求。

测试覆盖文件保真、草稿修订、原稿冲突、备份、保存中断与命令行边界。开发用 `DIFFEDITOR_DATA_DIR`、`DIFFEDITOR_PIPE` 可将测试草稿和接口完全隔离；这些变量不需要普通用户设置。
